Key Technologies

GEM VM

GEM VM creates delta, epsilon, and tilt parameters that conform to regional geology.

It flattens COCA/CACA gathers in Z, X, and Y dimensions and maximizes illumination in azimuth, angle, and offset.

The system minimizes parameter crosstalk prior to Full Waveform Inversion (FWI).

Generate: Creates beam forming for data analysis

Align: Calculates 6D residuals for each beam (inline, crossline, depth, offset X, offset Y, and reflector azimuth)

Tomography: Performs joint inversion for velocity, delta, and epsilon parameters simultaneously

Accurate estimation of velocity, delta, and epsilon requires a rich set of P-wave propagation angles in each tomography cell.

In FWI, direct arrivals have a limited range of propagation angles, which limits resolution between anisotropic parameters.

GEM takes advantage of full azimuth (FAZ) data to:

  • Generate 6D picks for every beam, creating a rich set of propagation angles
  • Simultaneously invert for velocity, delta, and epsilon
  • QC with COCA/CACA gathers to validate the earth model

Step 1: Align Residual Estimation

  • Estimates 6D spatial and temporal shifts of a beam along its shot/receiver ray path
  • 6D picks minimize cycle skipping
  • One shift per beam (not per location) with no dip limitation

Step 2: Inversion

  • One linearized equation per beam
  • Velocity model updated along the migrated ray path of each aligned residual
  • Iterative conjugate gradient method provides least squares solution
  • High quality results from 6D residual alignments and rich angles/azimuths

Quality Control (QC)

COCA/CACA gathers are 5D quality control tools for velocity model validation.

COCA/CACA Z:

  • Sensitive to vertical velocity and azimuthal variations
  • X and Y positions are constant while Z varies
  • Used to QC residual moveout, source/receiver offsets, and azimuth on low-dip reflectors

COCA/CACA X & Y:

  • Sensitive to horizontal velocity errors
  • Z is constant while X or Y varies
  • Used to QC residual moveout, source/receiver offsets, and azimuth on steep-dip reflectors

FARIS (Full Azimuth Ray Illumination System) provides detailed analysis of seismic illumination patterns across different azimuths, angles, and offsets to optimize data quality and imaging.

Selective Demigration is a QC technique that reverses the migration process on specific portions of the data, allowing geophysicists to validate velocity models and troubleshoot imaging issues.

GEM Technology Enhances Shot-Based Wave Equation Technologies

GEM technology is complementary to traditional geophysical algorithms:

  • Kirchhoff
  • WEM (Wave Equation Migration)
  • RTM (Reverse Time Migration)
  • FWI (Full Waveform Inversion)

Our Focus:

  • Reducing model uncertainty with QC tools to measure errors in velocity, delta, epsilon, tilt, and structural positioning
  • Utilizing proprietary algorithms to minimize parameter crosstalk
  • Evaluating robustness of existing FWI velocity models
  • Developing geologically conforming anisotropic VMs as input to FWI
